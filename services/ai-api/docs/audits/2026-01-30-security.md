## Findings (Detailed)

### F-01 — Missing JWT auth and policy-based authorization in Presentation layer
- **Severity:** High
- **Evidence:**
  - API pipeline registers controllers, security headers, and rate limiting, but no authentication/authorization middleware or service configuration is present (`src/SaasTemplate.AiApi.Api/Program.cs:L83-L120`).
  - Controllers do not apply `[Authorize]` policies on endpoints (`src/SaasTemplate.AiApi.Api/Controllers/WorkItemsController.cs:L13-L79`).
  - Baseline requires JWT bearer authentication and policy-based authorization (`docs/standards/security-baseline.md:L20-L56`).
- **Risk:** All endpoints are effectively anonymous, enabling unauthorized read/write access to Work Items.
- **Remediation:**
  1. Add JWT bearer authentication configuration and register authorization policies per baseline.
  2. Add `app.UseAuthentication()` and `app.UseAuthorization()` in the middleware pipeline.
  3. Apply `[Authorize(Policy = "...")]` to endpoints and allow explicit anonymous access only when configured for local development.

### F-02 — HTTPS redirection/HSTS not enforced in the pipeline
- **Severity:** Medium
- **Evidence:**
  - Pipeline does not include `UseHttpsRedirection()` or `UseHsts()` (`src/SaasTemplate.AiApi.Api/Program.cs:L113-L120`).
  - Security headers middleware only appends HSTS when requests are already HTTPS (`src/SaasTemplate.AiApi.Api/Middleware/SecurityHeadersMiddleware.cs:L21-L33`).
  - Baseline requires HTTPS redirection and HSTS in non-development environments (`docs/standards/security-baseline.md:L83-L91`).
- **Risk:** HTTP requests are not forced to HTTPS, and HSTS is not enforced consistently, increasing downgrade and MITM risk in production.
- **Remediation:**
  1. Add conditional HTTPS redirection and HSTS in Program.cs for non-development environments.
  2. Configure forwarded headers if running behind a reverse proxy so HTTPS detection is accurate.

### F-03 — Development credentials committed in configuration and compose defaults
- **Severity:** Medium
- **Evidence:**
  - RabbitMQ password is set in `appsettings.Development.json` (`src/SaasTemplate.AiApi.Api/appsettings.Development.json:L5-L12`).
  - `.env.example` and `docker-compose.yml` include default development passwords (`.env.example:L11-L26`, `docker-compose.yml:L11-L54`).
  - Baseline requires no secrets in config files and `.env.example` without real values (`docs/standards/security-baseline.md:L121-L145`).
- **Risk:** Committed credentials can be reused unintentionally or leak to shared environments; defaults may be deployed without overrides.
- **Remediation:**
  1. Replace committed passwords with placeholders (e.g., `CHANGEME`) in `.env.example` and `appsettings.Development.json`.
  2. Update compose defaults to require explicit values via environment variables.
  3. Document required environment variables in README/quickstart if necessary.

## Positive Observations
- Input validation exists for work item creation requests using FluentValidation (`src/SaasTemplate.AiApi.Api/Validators/CreateWorkItemRequestValidator.cs:L10-L28`).
- Security headers middleware adds CSP, X-Content-Type-Options, X-Frame-Options, and Referrer-Policy. It also adds the deprecated `X-XSS-Protection` header, which could be removed in favor of the existing CSP header (`src/SaasTemplate.AiApi.Api/Middleware/SecurityHeadersMiddleware.cs:L21-L33`).
- Rate limiting is enabled with a global rule (`src/SaasTemplate.AiApi.Api/Program.cs:L83-L102`).
- SQL access uses EF Core and parameterized raw SQL in the outbox repository (`src/SaasTemplate.AiApi.Infrastructure/Persistence/Repositories/OutboxRepository.cs:L24-L39`).
- Redis connection logging redacts passwords before writing to logs (`src/SaasTemplate.AiApi.Infrastructure/Caching/RedisCacheService.cs:L145-L180`).

## Remediation Plan (Prioritized)
1. **Immediate (High):** Implement JWT auth + authorization policies and enforce authorization on endpoints (F-01).
2. **Short-term (Medium):** Enforce HTTPS redirection and HSTS for non-development environments (F-02).
3. **Short-term (Medium):** Remove committed passwords and update example defaults to placeholders (F-03).
