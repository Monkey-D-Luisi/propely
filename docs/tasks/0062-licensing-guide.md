## Goal
Write a comprehensive licensing guide that explains the template's license terms in plain language for end users.

## Context
The LICENSE file and EULA (task 0059) contain legal language. End users need a plain-language guide explaining what they can do, what they can't do, and how support/updates work.

## Scope
### In scope
- What's included in the template
- Permitted uses (building products, internal tools, client projects)
- Restrictions (no redistribution, no resale of template)
- Attribution requirements
- How to deploy (brief, link to getting started)
- How to get support
- How to receive updates
- FAQ section

### Out of scope
- Legal advice
- License enforcement mechanisms

## Requirements
- R1: Guide is in plain language (not legalese)
- R2: Covers all common questions about licensing
- R3: Clear examples of permitted vs prohibited use

## Acceptance Criteria
- AC1: Document exists at `docs/licensing-guide.md`

- AC3: FAQ section covers common questions
